# TEP event matching

This panel preserves constraint violations and event representations while comparing three distinct solvers and three matching-cost inputs. The [locked protocol](../benchmark/protocol/event_matching_v1.md), [full Chinese report](EVENT_MATCHING_REPORT_zh.md), and [released predictions](../results_and_logs/summary/event_matching_v1/README.md) record all positive and negative outcomes.

| Identity | Actual computation | Comparison boundary |
|---|---|---|
| AEC-Prototype | Supplied `MyCover/Select/Dis/Cost` operating on actual violation and representation intervals | Strict and relaxed empirical mandatory signatures are separate rows |
| AEC-CostAdapted | Explicit nonnegative edge-cost matrix with the stated remaining-cover selection procedure | It does not encode learned distances as fictitious intervals and is not renamed as the original AEC |
| MinExplain | Opening cost 1 plus violation-assignment costs, solved by density greedy | This later objective is distinct from both preceding methods |

For each cost-adapted solver, interval-only, raw 64-point channel trajectories, and frozen Chronos-2 representations are compared on the **same relaxed candidate graph**. Temporal costs do not add candidates or erase unmatched violations. The prototype receives the true intervals, not an inverse construction that forces an arbitrary learned distance.

## Reproduce a fresh locked run

Use a separate GPU environment and a fresh output directory. The released original LOCK is immutable evidence; a fresh run creates its own lock and fitted artifact.

```bash
python -m pip install -e '.[gpu,chronos]'
python data/download.py tep
python -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='amazon/chronos-2', revision='29ec3766d36d6f73f0696f85560a422f50e8498c', local_dir='models/chronos2')"
bash run.sh formal event-matching --stage develop --data data/raw/tep --model models/chronos2 --output results_and_logs/runs/tep-event
bash run.sh formal event-matching --stage test --data data/raw/tep --model models/chronos2 --output results_and_logs/runs/tep-event
```

`--protocol` can explicitly identify a saved protocol; the default is the released event protocol. Data, model, fitted object and source hashes are checked before test prediction. `TEST_STARTED.json` prevents a second test execution in the same output directory. Local `fitted.pkl` is generated by development and consumed by the same run; no fitted pickle or model weights are distributed here.

The recorded run used frozen Chronos-2 120M, revision `29ec3766d36d6f73f0696f85560a422f50e8498c`, model SHA256 `ddcda3c7508bf2528087723e98a20707cc04b7f370ae275a9fd88078ddba4f42`. Recorded versions are Torch 2.11.0+cu128, NumPy 2.3.2, SciPy 1.18.0, scikit-learn 1.9.0, chronos-forecasting 2.3.1, transformers 5.13.1 and pandas 3.0.3. The core CPU validation has a separate tested environment. Changing those versions can change numerical reproduction.

## Scope and observed outcome

The 44 classic TEP source files yield 88 fit, 22 development, 22 calibration and 267 test windows from 22 test trajectories. Window length and stride are 64. Evaluation is conditional on the fault interval; this is not end-to-end onset detection. Empirical signatures use labeled fit windows. Only one normal calibration window is available. A trajectory has multiple correlated windows and is the independent reporting unit.

Frozen Chronos-2 increased MinExplain window macro F1 from 0.3146 with raw temporal distances to 0.3786, and trajectory Top1 from 0.4091 to 0.5455. Explanation-set F1 increased only from 0.3243 to 0.3317. Normal false explanations remained 0.8000. The stronger statistical SVM reached window macro F1 0.5253; the independent, same-split Random Forest controls averaged 0.5921. These observations support a limited matched-structure ranking gain, not overall superiority or foundation-model necessity.

The fixed missing-knowledge panel removes F21 and reports known false rejection, unknown recall and AUROC without choosing thresholds on test labels. Its outcome does not establish reliable open-set diagnosis. Full per-class results, candidate diagnostics, normal errors and negative results remain available.

## Provenance

The current method module is byte-identical to its supplied implementation. The public runner only makes the protocol path configurable and relocates the entry point. [`event_source_mapping.json`](event_source_mapping.json) records original and released hashes. The exact executed source tree is preserved beside the released results and matches the original LOCK. The original descriptive metadata typo concerning the number of normal calibration windows is retained in that snapshot; its correction is documented without changing predictions, parameters or LOCK.
