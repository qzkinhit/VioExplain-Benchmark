# TEP 正式事件匹配增量报告

本轮完成了原始异常表征和覆盖结构上的正式 TEP 事件解释实验。冻结 Chronos-2 120M 在同候选图、同事件知识、同 MinExplain 求解器下优于原始时序距离，但整体低于强无基模统计分类器。正常误解释与缺知识拒识均未达到可用水平。本轮不支持最优性能、基模必要性或可靠故障确诊的主张。

## 数据、模型与执行边界

数据为经典 TE_process 的 F01 至 F21 故障编号及正常类 0，共 44 个原始文件。长度 64 的非重叠窗口产生 88 个 fit、22 个 validation、22 个 calibration 和 267 个 test 样本，后者来自 22 条轨迹。训练故障预先排除 20 点 warm-up，测试故障按经典发布约定从 160 点开始。窗口评价条件于给定故障区间，不是端到端起点检测。每类仅有一条训练与一条测试轨迹，不能把 267 个窗口或随机种子当作独立故障复现。

正常 calibration 实际只有一个完整窗口。此前 COMPLETE.json 的静态限制文字误写成三个，现仅纠正该描述，并保留更正前文件、metadata_corrections.json 和实际运行源快照。预测、参数、LOCK.json 均未改动。

实验全部运行于远端 GPU 服务器的独立目录，仅用 GPU 进行冻结编码，模型为官方 Chronos-2 120M，revision 为 `29ec3766d36d6f73f0696f85560a422f50e8498c`。权重 SHA256 为 `ddcda3c7508bf2528087723e98a20707cc04b7f370ae275a9fd88078ddba4f42`。encoder 每通道所有 token 均值经 fit-only 标准化与 16 维全 SVD PCA 后进入匹配代价。未微调基模，没有基模分类头。全 SVD、编码器 eval 和确定性距离不需要通过三个随机种子制造额外独立性。

代码在远端通过五项不变量测试，涵盖区间距离、时序代价不改变候选图、缺知识时未解释证据保留、空正常集合和不伪造必现表征，以及推理不重拟合 PCA。正式 test 在 LOCK 写入后仅执行一次，TEST_STARTED.json 禁止重复测试。来源、模型、配置、数据哈希及测试前锁定状态均已保留。fairness_audit.json 核实本轮与正式分类基线的全部 44 个数据哈希及所有切分窗口逐项相同。

## 保留的原方法与新增接口

AEC-Prototype 直接以真实违反程度区间和事件知识区间调用现有 MyCover/Select/Dis/Cost。严格候选要求所有必现表征存在；放宽候选允许最多一半必现表征缺失。这里的必现与可能表征由每类四个 fit 窗口的经验频率建立，不是专家确认的工业因果知识。本轮仅包含单序列均值、标准差和趋势约束，关联规则为空，不能据此评价原框架所有约束与知识更新功能。

AEC-CostAdapted 使用明确的非负代价矩阵接口，不将学习代价编码为虚构程度区间。它保留当前全为单序列且无关联规则设置下的覆盖选择操作。MinExplain 则优化固定开启代价 1 加逐违反指派代价，求解器为现有密度贪心。二者不共用“原 AEC”的名称或理论保证。

所有成本适配方案共享同一放宽候选图。边代价融合区间距离和时序原型距离，同时保留必现缺失与可能表征出现率惩罚。原始时序对照使用保留正常绝对尺度的 64 点通道序列；基模只补充同通道匹配代价。未解释违反始终单列。验证集只做预定的 λ∈{0,0.25,0.5} 一次选择，MinExplain 的原始时序和基模版本均选择 λ=0.5，AEC-CostAdapted 两者均选择 λ=0.25。

正式基线代理的同数据同切分结果进一步显示，均值、标准差、趋势上的 shrinkage LDA 窗口 macro F1 为 0.5266，RBF SVM 为 0.4040，500 棵树随机森林三个种子的 macro F1 为 0.5962、0.5934、0.5867，平均 0.5921。随机森林轨迹 Top1 为 0.6818、0.7273、0.7273。这些结果均高于当前 MinExplain 加基模方案。因此，胜过原型 AEC 不等于胜过有效的事件分类方法。

冻结 Chronos-2 相对同结构原始时序使窗口 macro F1 增加 0.06395，Top1 增加 15/267，轨迹分类多判对 3/22。按各类窗口 Top1 比较，7 类改善，4 类下降，11 类持平；22 个窗口仅基模版本正确，7 个窗口仅原始时序版本正确。这是描述性配对结果，不使用相关窗口计算独立样本显著性。平均解释数量由 2.775 增至 2.828，解释集合 F1 仅增加约 0.0074，说明主要收益表现在排序，完整解释集合仍不准确。

## 负结果与诊断

严格经验必现条件下，真实故障进入候选图的比例仅为 0.1865。放宽后升为 0.75；该数值在区间、原始时序及基模版本之间完全相同。严格条件在少量训练窗口上形成的经验“必现”响应不能稳定覆盖另一条测试轨迹。放宽条件能改善候选召回，却同时让正常误解释上升，不能将这部分收益归因于基模。

在真实故障已进入候选图的窗口中，MinExplain 的区间、原始时序、基模 Top1 分别为 0.3439、0.4392、0.5185。基模提高了固定候选图内的区分，但候选漏失使总体正确率存在直接上限。覆盖目标还倾向选择多个响应相近的事件，因此 66.3% 的解释集合召回同时伴随仅 22.1% 的集合精度。低代价覆盖不是正确事件恢复的充分条件。

正常测试共有 15 个窗口，放宽图下 12 个产生非空事件解释，正常事件分类 Top1 为 0。轨迹级的多数集合聚合得到正常误解释 0，但这仅说明没有同一错误事件在半数窗口中重复出现，不能证明正常窗口已被可靠识别。单个正常 calibration 窗口不支持稳定的正常错误率校准。

固定删除 F21 知识的试验中，未解释违反比例的已知 calibration 95%上分位等于 1。严格大于阈值的拒识规则因此不拒识任何窗口，未知召回和已知误拒均为 0。放宽图的 AUROC 为 0.8824，但实际锁定阈值没有实用召回，不能只报告 AUROC 宣称开放集能力。该试验只删除事件知识，fit 的共享尺度和 PCA 未排除 F21 轨迹，所以它是缺知识测试，不是完整留故障类的分布外泛化测试。

## 理论与写作可用结论

本轮支持将候选保真与候选内区分分开分析。任何只改变边代价且保持图不变的时序方法，都不能恢复被候选构建删除的真实事件；同图条件下观测到的增量可以归因于代价的时间信息，但不能推出原约束表征的充分性。MinExplain 的成本近似保证只对应给定候选图和给定代价的优化误差，不保证预测事件真实，也不能转用为原 MyCover 的保证。

论文可将本轮作为真实故障编号上的受限正结果和完整失败诊断。尚不能将简单距离融合称为已验证的深层方法创新，不能由一次 TEP 切分声称基模必要，也不能补造 Unknown 故障的物理机制。后续若改候选可信条件、正常拒识或事件集合目标，必须新建预先锁定的独立评价，不能继续据这批 test 结果选择超参数。知识更新仍未运行，当前方法保留了未解释证据接口，不构成更新正确性的实验验证。
