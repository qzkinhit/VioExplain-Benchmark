# Provenance and release boundary

The release is an allowlist export from the VioExplain research implementation. [`export_manifest.json`](export_manifest.json) records source-relative paths and SHA256 hashes of inherited project modules. The public API, CLI, package metadata, data downloader, and release documentation were added for this release. Source and release hashes may differ when comments or interface documentation are corrected; functional changes must appear in the changelog.

The inherited components implement the original violation/representation/covering/update sequence, the minimum-cost explanation formulation, and later experimental residual and joint-inference components. The release does not rebrand the original dissertation contribution as a new foundation-model method.

No manuscript or dissertation text, private FPP measurements, teacher Word files, local SSH configuration, host address, private key, model weight, or copied third-party baseline checkout is exported. Raw public data are downloaded separately into ignored directories and retain upstream notices. The reference repositories DemandClean, UniClean, and CARVEPrep informed organization and terminology only; their manuscript prose and source files are not bundled here.

The root MIT license applies to project-owned code. No additional third-party license is inferred merely from an algorithm name. If a future contribution includes external code, record its immutable upstream revision, exact notice, modifications, and redistribution terms before adding it to the release.

`AEC-Prototype` retains the supplied legacy event-covering procedure. `MinExplain` is a later formalization with a different opening-plus-assignment objective and different solvers. The latter is not relabeled as the original algorithm. The supplied original English manuscript and legacy code identify the prototype lineage.
