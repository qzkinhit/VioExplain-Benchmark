# Results

`summary/` contains verified, sanitized release snapshots. `runs/` is the recommended, Git-ignored destination for new reproduction runs. The source snapshots inside released results preserve the executed implementation independently of later entry-point changes.

See [benchmark status](../docs/BENCHMARK_STATUS.md) and [the recording contract](../docs/EXPERIMENT_RECORDS.md). Console and execution evidence belong in `../log/`. A successful process exit is not a validation of scientific claims.
