# TEP 正式事件匹配锁定协议

本协议在首次测试预测前写定。异常事件为官方轨迹标识 F01 至 F21，正常类为 0。F16 至 F20 的发布描述是 Unknown，F21 的物理语义未核实，不补写物理解释。train20 是本研究预先排除的 warm-up，不称为官方异常起点。测试故障从 160 开始的约定有 MIT 发布包 temain_mod.f.txt 中 8 小时注入、每 3 分钟输出的依据，相关原文由正式基线代理归档。

## 数据与切分

仅使用 MIT 经典 TE_process 的 44 个原始 dat。长度 64，步长 64，只取完整窗口。每条 train 轨迹按原始索引 60%、20%、20% 分为拟合、选择、校准。fault 拟合从 20 开始；正常从 0 开始。fault test 从 160 开始，正常 test 从 0 开始。训练、验证和校准不跨边界拼接。统计量、PCA 与距离尺度只在 fit 拟合。共有一条训练与一条测试轨迹对应每类，窗口不能当作独立故障，随机种子不增加独立轨迹数。

## 事件知识与违反

每通道提取均值、标准差与最小二乘趋势。以正常 fit 窗口均值为中心，以正常窗口标准差和正常点方差推导的标准误下界之最大值为尺度，构造有符号标准偏差。超过 3 的同通道、同统计约束产生违反，程度区间为偏差正值上下各 0.5。每类 fit 的经验出现率至少 0.75 者为必现表征，至少 0.25 者为可能表征；程度区间包络该类出现的 fit 违反。这里是标签辅助的经验响应知识，不能声称为专家确认的因果规律。不存在必现表征的类不能凭空补一个表征。

严格候选要求所有必现表征存在。放宽候选最多允许一半必现表征缺失，且至少有一项相同约束违反。两者的对照用于分离候选放宽与时序增量。所有成本适配方法共享放宽候选图，不用时序代价新增边，无法匹配的违反单独保留。

## 原型与成本增量

AEC-Prototype 使用真实程度区间调用现有 MyCover/Select/Dis/Cost，严格与放宽候选各报告一份。它采用原事件覆盖过程，不借用 MinExplain 的目标或保证。本协议没有多序列约束和关联规则，因此不声称覆盖了原框架全部功能。

AEC-CostAdapted 明确以代价矩阵重写选择接口，不编码虚构程度区间。它在本实验全为单序列约束、关联规则为空的设置中，先按每项违反初始最小候选代价排序，再为当前违反选择剩余覆盖总成本最小的事件，删去其覆盖项。候选缓存只指向已选择事件，原实现中缓存的未选择条件不会增加新事件。不能由这些操作相同直接声称原理论保证迁移。

MinExplain 使用现有密度贪心，目标是事件开启代价加逐违反指派代价。每个事件开启代价固定为 1。AEC-CostAdapted 与 MinExplain 的候选图、代价和输出集合均不限制为真值一个事件。

逐边非负代价为 0.8[(1−λ)区间交并距离 + λ时序距离] + 0.1必现缺失比例 + 0.1(1−经验出现率)，数值上界截为 0.999999。时序距离以同类 fit 窗口逐通道近邻为原型，尺度为类内相邻 fit 对的距离中位数，再以 d/(1+d) 有界化。标准化与共享 16 维全 SVD PCA 均只拟合 fit。无基模时序控制使用保留绝对正常尺度的 64 点轨迹。基模版本使用冻结 Chronos-2 120M，revision 29ec3766d36d6f73f0696f85560a422f50e8498c，逐窗口允许通道交互，对每通道所有 encoder token 求均值；原尺度由原约束通路保留。

每个求解器和时序表示只选择一次 λ∈{0,0.25,0.5}，按 validation macro F1、解释集合 F1、较小 λ 依次排序。区间版本固定 λ=0。独立强无基模控制为统计特征 RBF SVM 和原始窗口 StandardScaler/PCA64/RBF SVM，C 仅取 {1,10}，gamma 为 scale。统计特征包含均值、标准差、趋势、10%/90%分位、差分标准差、lag1。正式代理另外提供同协议 SVM、LDA、RF；不能赋予基模更多标注窗口。

## 输出、缺知识与测试约束

事件 Top1 与 Top3 使用求解器选择顺序，再按均值边代价补充候选。解释集合直接使用求解器完整输出，真值 fault 是单元素集，正常是空集。无违反返回正常；有违反无候选返回未识别类 −1，解释为空。报告全部 22 类 macro F1、事件集合微平均 P/R/F1、正常误解释比例、未解释证据及解释数量。轨迹分类用窗口多数票，票数相同按编号确定；轨迹解释采用至少半数窗口选择的事件。它不是端到端故障检测，事件身份评价条件于给定故障区间。

缺知识协议固定删除 F21 知识，其他方法条件不变。未知分数为未解释违反比例，在已知 calibration 类 0 至 20 上取 95%上分位为阈值，严格大于阈值才拒识。报告 F21 召回、已知误拒与 AUROC；不依赖 F21 test 选择阈值，不称为一般开放集保证。

先写 LOCK.json、来源/数据/模型/配置 SHA256、fit对象哈希，再开始一次 test。测试开始标记阻止重复测试。不因 test 负结果换参数或改方法。失败日志与完整验证网格保留。全流程在远端运行，本机只编辑源文件和接收产物。
